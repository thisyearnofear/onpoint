# OnPoint — ChatGPT directory starter prompts

User-language examples for the plugin listing (Example Prompts). Prefer free discovery tools. Do **not** put pricing, trials, or checkout CTAs in the listing text.

1. **Will these fit me?** Browse OnPoint curators with live sizes and stock I can check before I buy.
2. **Show me a storefront** — pick a curator and list what's in stock with sizes and prices.
3. **Analyze this outfit photo** and suggest what from OnPoint would match.
4. **What African textile is this?** Identify the pattern, then find similar pieces on OnPoint.
5. **Find curated looks** like this style so I can compare before trying anything on.

Paid virtual try-on and purchase stay on OnPoint / agent commerce (`try_on`, `buy_item` via x402) — not as directory prompts that imply in-chat checkout.
